Fast, friendly temporary email

Usage: tmpmail [OPTIONS] [COMMAND]

Commands:
  message      Messages [ls, read, latest, new-mail, unread]
  inbox        Named inboxes [new, inboxes, use, watch]
  attachment   Attachments
  provider     Providers
  config       Configuration
  copy         Copy address
  doctor       Diagnose setup

Options:
      --inbox <NAME>
      --provider <PROVIDER>
      --no-provider <PROVIDER>
      --json
      --no-color
      --timeout <DURATION>  [default: 15s]
      --quiet
      --verbose
  -h, --help
  -V, --version

Mail.tm functionality is powered by Mail.tm: https://mail.tm
